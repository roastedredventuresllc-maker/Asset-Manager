Three decisions I made before writing this, so you know the reasoning:

Journey: The plan picker was the worst remaining friction — three plans to compare at the exact moment you want zero hesitation. I killed it. New model: generating is free with no account, and going live is one decision (daily budget) + one card entry. The AI even picks the channel split for you (shown, overridable). Account creation happens implicitly through Stripe checkout — no signup wall ever.

Pricing: Flat subscriptions misalign with how this product creates value. Agencies price as % of spend, and that’s what scales: a customer at $75/day runs $2,250/mo through you — 10% is $225/mo from one user vs. your old $30 subscription. New structure: free to generate, then ad budget + 10% service fee ($29/mo minimum) to be live. One sentence, one number. A $99/mo Pro tier (5% fee, multiple campaigns, all channels, custom domain) exists as a post-launch upsell, never shown at checkout. I also killed the $2-per-revision charge — it’s anxiety-inducing nickel-and-diming over pennies of cost. Free drafts get 3 revisions (cost control); live customers get unlimited.

Replit fit: Replit Agent one-shots most reliably on its native stack — Vite + React + Express + Replit PostgreSQL with Drizzle, Replit Object Storage, Secrets, and Scheduled Deployments for crons. The prompt uses exactly that, keeps external dependencies to four (Anthropic, fal.ai, Stripe, sharp), and mandates a mock mode for the ad platforms so the product works end-to-end today while Meta/TikTok approvals process.

The user journey (build exactly this — it is the product)

One page that evolves through states. No dashboard, no nav bar, no signup wall.

1. Input. Full-viewport centered. Serif headline “What are you launching?” (“launching?” italic, 50% opacity). One white card: textarea, paperclip/drag-drop photo upload, circular black send button. Four muted example chips. No account needed.

2. Working. Centered CSS spinner, one italic serif line: “Building your campaign…”

3. Briefing. Reads like a one-page agency deliverable, top to bottom: tiny logo top-left (resets) → centered brand name in ~88px serif + italic tagline → small-caps label “THREE ADS” → three-column grid of ad images (generated async; show shimmer placeholders that fill in; under each: tiny-caps strategic angle + headline) → small-caps label “LANDING PAGE” → the actual landing page in a chromeless full-width iframe → centered black button “Ship {BrandName}” with rocket icon → quiet text link beneath: “Not quite right? Tell us what to change.”

4. Revision chat. The text link opens a bottom sheet (65% viewport): serif title “What’s off?”, chat thread (user = black right bubbles, AI = white left cards), input bar. Each message applies the change and the briefing re-renders live behind the sheet. Drafts get 3 free revisions; live campaigns get unlimited. When a draft hits 0, show one line: “Ship it to unlock unlimited revisions.”

5. Ship. Clicking Ship opens ONE modal, ONE screen — no plan comparison, no channel pills as a required decision:

	•	Budget: three preset cards — Starter $25/day, Growth $75/day, Scale $200/day — each with projected daily reach range; AI-recommended preset pre-selected with a small “recommended” tag; “custom amount” link reveals a number input.
	•	Channels: one auto-set line, e.g. “Running 60% Meta · 40% TikTok — picked for your audience” with a small “Adjust” link that expands sliders. Not a required decision.
	•	Price line: “Your ad budget + 10% service fee · $29/mo minimum · includes hosting, image generation, unlimited revisions · pause anytime.”
	•	One button: “Ship {BrandName} →” → Stripe Checkout (collects email + card; subscription = $29/mo base + metered usage item for spend+fee). On webhook success, create the user account from the Checkout email, attach the draft campaign, fire the publish pipeline, redirect to Live. Send a magic-link email so they can return (simple signed-token link; no passwords anywhere).

6. Live. Green check circle → “{BrandName} is live.” in serif → the live landing URL (clickable) → a quiet metrics strip (impressions / clicks / spend) polling every 30s → “Pause campaign” text link → “Launch another →”. Campaigns run continuously until paused; send a weekly summary email stub (log to console in v1).

Returning users (via magic link) land on a minimal campaign list: each row = brand name, status dot, spend today, click → its briefing/live page. Nothing else.

Pricing & billing logic (enforce server-side)

	•	Free: unlimited campaign drafts, 3 revisions per draft, full preview. No account required.
	•	Live: $29/mo platform subscription + 10% of ad spend (Stripe metered usage, reported nightly), unlimited revisions, Meta + TikTok, hosted landing page.
	•	Pro $99/mo: 5% fee, up to 5 simultaneous live campaigns, Google + LinkedIn channels, custom domain. Surfaced only in the account page and in a one-line upsell when a user tries to launch a second concurrent campaign — never in the ship flow.

AI campaign generation

POST /api/generate — brief (+ optional product photo) → Claude claude-sonnet-4-5 → strict JSON: brand name, tagline, category, palette (4 hex), audience spec (age range, interests, geo default US), recommended channel split with one-line rationale, recommended budget preset, 3 ads (hook 5-8 words, body 10-15 words, CTA, angle label, detailed imagePrompt written as a photographer’s brief, 2 gradient hexes), landing copy (hero, sub, 3 features, social proof, CTA). Parse defensively: slice first { to last }. Moderation pass before any publish: run copy through Claude against Meta’s prohibited-content categories; block with a clear user-facing message if flagged.

POST /api/revise — campaign JSON + request → Claude applies only the requested change, returns same shape + a visualChanged boolean; re-enqueue image jobs only if true.

Image generation pipeline

DB-backed job queue (jobs table + a worker route hit by a Scheduled Deployment every minute, secured by a secret header). Per campaign, 3 images via fal.ai:

	•	Product photo uploaded → Gemini 2.5 Flash Image (Nano Banana) on fal.ai, image-edit mode: product photo + scene prompt → product composited into a generated scene.
	•	No photo → FLUX 1.1 Pro text-to-image.
	•	Ad 3 (typography-led) → Ideogram v3 for accurate text rendering.
	•	Sizes: 1080×1080 (ads 1, 3), 1080×1920 (ad 2).
	•	Composite brand name, headline, and CTA button onto each image server-side with sharp (SVG text layer → flat PNG). Store in Replit Object Storage; save URLs + per-image cost on ad_assets.
	•	Fallback: if FAL_API_KEY is absent or a job fails twice, render designed SVG gradient ads (linear gradient bg from the ad’s hexes, radial light overlay, product photo with drop shadow if available, copy overlaid) so the product never breaks. Upload photos are resized client-side to max 1024px JPEG before sending.
